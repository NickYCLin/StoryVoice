# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available.

Include affected version/commit, reproduction steps, impact, and a minimal proof of concept. Do not include real API keys, copyrighted books, generated private audio, or user data.

## Sensitive data boundary

StoryVoice repositories must not contain:

- LLM / TTS provider credentials
- uploaded electronic books
- generated audio or analysis output
- production database dumps or runtime volumes
- private voice samples

DRM circumvention is outside project scope.
